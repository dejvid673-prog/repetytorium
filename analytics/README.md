# Analityka

Celem jest rozwijanie biblioteki na podstawie rzeczywistych potrzeb użytkowników.

Zbieranie danych wymaga:

- jawnego celu;
- katalogu zdarzeń;
- podstawy prawnej lub zgody;
- minimalizacji;
- retencji;
- pseudonimizacji;
- kontroli dostępu;
- możliwości usunięcia;
- oddzielenia kontaktu e-mail od zachowania na stronie.

Centralny magazyn jest logicznym punktem analizy, nie zgodą na nieograniczone gromadzenie danych.
