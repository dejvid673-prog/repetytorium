# Zasoby wizualne

Katalog przechowuje grafiki używane przez repetytorium oraz informacje o ich pochodzeniu i prawach.

## Planowane grupy

- `icons/`;
- `thumbnails/`;
- `illustrations/`;
- `photographs/`;
- `licenses/`.

## Wymagania

Każdy zasób powinien posiadać:

- trwały identyfikator;
- autora lub źródło;
- typ licencji;
- zakres użycia komercyjnego;
- informację o wymaganym oznaczeniu;
- datę pozyskania albo utworzenia;
- powiązania z artykułami;
- tekst alternatywny;
- format, rozmiar i wersję zoptymalizowaną.

Nie wolno publikować grafiki tylko dlatego, że została znaleziona w wyszukiwarce internetowej. Emoji nie są docelowym zamiennikiem ikon.
