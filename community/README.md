# Współpraca czytelników

Kanał początkowy: e-mail.

Dozwolone zgłoszenia:

- błąd;
- propozycja tematu;
- pytanie;
- zdjęcie;
- opis przypadku.

Publikacja wymaga moderacji, weryfikacji, anonimizacji i odpowiedniej zgody. Publiczne forum nie należy do początkowego zakresu. Przyszła biblioteka przypadków będzie zbiorem redagowanym, a nie automatycznie publikowanym strumieniem.
