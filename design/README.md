# Projekt interfejsu

Katalog przechowuje system projektowy, tokeny, komponenty, makiety HTML, zrzuty porównawcze i zatwierdzone decyzje wizualne.

Kierunek:

- profesjonalny i spokojny;
- czytelny;
- związany z wodą i naturą;
- bez wyglądu dokumentu Word;
- bez dziecięcej przesady;
- bez emoji jako ikon;
- WCAG 2.2 AA;
- mobile-first z kontrolą desktop.
