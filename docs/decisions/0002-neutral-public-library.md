# ADR-0002: Neutralna publiczna biblioteka

Status: accepted  
Data: 2026-07-16

## Decyzja

Repetytorium jest publicznie czytelną biblioteką wiedzy. Nie reklamuje produktów, nie rekomenduje ich i nie przechowuje relacji artykuł–produkt. Czytanie nie wymaga konta.

## Konsekwencje

- treść jest oddzielona od sprzedaży;
- moduł nie potrzebuje relacji produktowych;
- SEO może indeksować publiczne strony;
- konto może być używane przez sklep, ale nie jest warunkiem dostępu do wiedzy.
