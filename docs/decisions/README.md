# Decyzje architektoniczne

Katalog przechowuje Architecture Decision Records — krótkie dokumenty wyjaśniające trwałe decyzje, ich kontekst, alternatywy i konsekwencje.

## Nazewnictwo

```text
NNNN-krotka-nazwa-decyzji.md
```

## Statusy decyzji

- proposed;
- accepted;
- superseded;
- rejected;
- deprecated.

Zmiana wcześniejszej decyzji nie usuwa jej z historii. Nowy ADR wskazuje decyzję zastępowaną.
