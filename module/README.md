# Moduł PrestaShop

Docelowy kod własnego modułu PrestaShop 9. Nazwa robocza: `stawexpertknowledge`.

Moduł nie może:

- modyfikować core;
- reklamować produktów w treści;
- publikować bez kontroli;
- przechowywać sekretów;
- traktować checkboxa jako pełnej historii weryfikacji.

Model przyszłych przypadków czytelników ma zostać przewidziany, ale interfejs pozostaje wyłączony do osobnej decyzji.
