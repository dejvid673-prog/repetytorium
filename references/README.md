# Zewnętrzne materiały referencyjne

Katalog przechowuje audyty zewnętrznych repozytoriów, narzędzi, wzorców i licencji. Nie przechowuje bezrefleksyjnych kopii całych projektów.

Przed użyciem elementu zapisuje się źródło, commit lub wersję, licencję, zakres zapożyczenia, modyfikacje, ryzyka i atrybucję.
