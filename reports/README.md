# Raporty

Raporty agentów i audytów trafiają do katalogów powiązanych z zadaniami albo wydaniami. Raport nie zastępuje zmian w dokumentacji nadrzędnej.

Minimalna zawartość:

- ID zadania;
- agent;
- wersja kontekstu;
- zakres;
- wejścia;
- zmienione pliki;
- testy;
- wyniki;
- niewykonane testy;
- ryzyka;
- kryteria akceptacji;
- następny krok.
