# Badania

Katalog przeznaczony na raporty głębokich badań i ich metadane.

## Planowany cykl

- `inbox/` — nowe, jeszcze niesprawdzone materiały;
- `accepted/` — przyjęte i kompletne;
- `processing/` — aktualnie analizowane;
- `completed/` — przetworzone, zachowane jako źródło;
- `rejected/` — odrzucone wraz z uzasadnieniem.

## Zasady

- Nie zmieniać treści oryginalnego badania.
- Materiały pochodne zapisywać poza plikiem źródłowym.
- Zapisywać datę, autora lub pochodzenie, zakres i identyfikator.
- Nie umieszczać danych klientów ani sekretów.
- Cytowania i źródła zachowywać w formie możliwej do zweryfikowania.
- Brak źródła albo sprzeczność musi zostać oznaczona, a nie uzupełniona zgadywaniem.

Dokładny format pakietu badawczego zostanie zdefiniowany w `schemas/`.
