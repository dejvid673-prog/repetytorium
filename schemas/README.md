# Schematy danych

Katalog będzie zawierał maszynowo walidowane kontrakty wymiany danych pomiędzy agentami i etapami workflow.

Planowane schematy:

- pakiet badawczy;
- plan artykułów;
- artykuł;
- źródło;
- zasób wizualny;
- powiązanie produktu;
- pakiet publikacyjny;
- raport kontroli.

Schematów nie należy tworzyć przed ustaleniem rzeczywistych pól na przykładzie pilotażowego badania. Każda zmiana niezgodna wstecznie wymaga wersjonowania i opisu migracji.
