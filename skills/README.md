# Skille projektu

Wszystkie skille specyficzne dla Repetytorium Staw Expert są tworzone i utrzymywane tutaj.

Przed utworzeniem skilla należy:

- sprawdzić rejestr;
- sprawdzić inne repozytoria wyłącznie referencyjnie;
- ocenić możliwość ponownego użycia;
- oddzielić reguły globalne od wyjątków zadania;
- zdefiniować testy;
- zapisać wersję i zależności.

Skill nie zastępuje kontraktu agenta i nie może zmieniać konstytucji.

## Miejsce zapisu

Skill projektu istnieje wyłącznie w tym repozytorium. Nie tworzymy drugiej kopii w osobistym katalogu skilli ani w innym repozytorium. Instalację lub podłączenie do narzędzia rozważamy dopiero jako osobny, audytowany etap.

## Źródła zewnętrzne

Kandydat znaleziony na GitHubie przechodzi `docs/GITHUB_SOURCE_INTAKE.md`. Wynik wyszukiwania, popularność albo licencja całego repozytorium nie zastępują audytu konkretnej ścieżki i commitu.

Pierwszy skill projektu: `coordinate-repetytorium/SKILL.md`.
