# Szablony

Szablony wymuszają jednakowe raportowanie i nie są dowodem wykonania pracy.

- `AGENT_AUDIT_REPORT.md` — audyt kontraktu, narzędzi, niezależności i testów agenta;
- `BRANCH_MANIFEST.yaml` — zakres, zależności, środowisko, audytorzy i testy gałęzi;
- `PHASE_GATE_REPORT.md` — dowody pozwalające zamknąć albo odrzucić bramę fazową.

Kopię szablonu zapisuje się w docelowym katalogu raportu. Nie modyfikuje się wzorca, aby „zaliczyć” istniejące zadanie.

- `TASK_BRIEF.yaml` — karta pojedynczego zadania A00;
- `PROJECT_STATUS_REPORT.md` — raport kierunku, pakietów, bram i blokad;
- `OWNER_DECISION.md` — warianty decyzji z analizą skutków;
- `SOURCE_MATERIAL_INTAKE.yaml` — przyjęcie instrukcji lub materiału właściciela;
- `EXTERNAL_COMPONENT_AUDIT.md` — audyt elementu znalezionego na GitHubie.
